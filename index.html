引擎是怎么工作的

没有 WebGL，所有画面都是 Canvas2D 上逐个三角形画出来的。四步：

  1. 01

    顶点变换

    每个网格把局部坐标乘上模型矩阵、再乘视图投影矩阵，得到裁剪空间坐标。所有顶点缓存在扁平 Float32Array 里，避免 GC 抖动。

  2. 02

    背面剔除 + 光照

    用面法线与视线方向的点积剔除背面；支持 lambert / phong / metal / toon / glass 等九种着色模式，逐面计算漫反射与高光。

  3. 03

    画家算法排序

    把这一帧所有可见三角形按深度从远到近排序，然后依次绘制。半透明材质因此天然正确，不需要深度缓冲。

  4. 04

    可选泛光

    带自发光的三角形额外画到一张半分辨率图层上，模糊后以叠加模式合成，得到霓虹辉光——代价只有一次 drawImage。

最小组件示例
<canvas id="stage"></canvas>
<script src="vendor/dse.js"></script>
<script src="vendor/fx.js"></script>
<script>
  const { Scene, Mesh, Light, geom, mat } = DSE;

  const scene = new Scene(document.getElementById('stage'), {
    bloom: 0.6, fog: { color: '#04060d', near: 5, far: 26 }
  });
  scene.add(new Light({ direction: [-0.5, 0.8, 0.6] }));

  // 液态金属球：每帧被正弦波推动的球体
  const g = FX.blobGeom({ radius: 1.4, amp: 0.16 });
  const blob = new Mesh(g, mat.metal({ color: '#c9d8ff', specular: 1 }));
  blob.spinY = 0.2;
  blob.onUpdate = () => g.updateBlob(scene.clock);
  scene.add(blob);

  // 360 个带受力的粒子
  scene.add(new DSE.Particles({ count: 360, shape: 'glow', twinkle: 0.8 }));
  scene.start();
</script>

怎么运行

两种方式，随便挑一种。

① 直接双击

每个站点都是自包含的静态页面，直接双击 index.html 就能看。 用相对路径引用 ../../vendor/，所以整个文件夹要一起移动。

注意：file:// 下 localStorage 在部分浏览器会被禁用，蒸汽波站点的留言板会退化为内存存储。

② 起一个本地服务（推荐）

仓库带了零依赖的静态服务器脚本：

node serve.js
# 然后打开 http://127.0.0.1:5178/

可以用环境变量换端口：PORT=8080 node serve.js
